Check sources and run required constant evaluation and const tests.

Usage:
  carven check [options] <source-file>...

Options:
      --timings Show total and stage timings on stderr
  -h, --help    Show this help

Sources include the fixed toolchain and working-directory Crafts roots.
No entry point is required.
Runtime code is checked without execution; no C++ files are generated.
Delegated native operations are checked by the C++ compiler.
