Carven compiler and runner

Usage:
  carven <source-file>... [-- <arguments>...]
  carven <command> [options] <source-file>...

Commands:
  compile      Generate C++ headers and sources
  check        Check sources and run const tests
  interpret    Run the supported language subset with the interpreter
  dump         Inspect tokens or the syntax tree

Options:
  -h, --help       Show this help
  -V, --version    Show the version

Source files without a command are compiled and run natively.
Use 'carven <command> --help' for command options.
