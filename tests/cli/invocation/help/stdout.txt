Carven Source-to-C++ Compiler

USAGE:
    carven [options...] <source-file>...
    carven dump tokens <source-file>
    carven dump ast <source-file>

OPTIONS:
    -o, --output-dir <dir>   Write generated files below this directory
                             (default: current directory)
    --stdout                 Print all generated artifacts for inspection
    --tests=default          Emit inline tests and the default runner
    --tests=external         Emit inline tests without a runner
    --linkage-domain <value>   Isolate the private generated namespace

DEVELOPER COMMANDS:
    dump tokens              Dump the token stream to stdout
    dump ast                 Dump the syntax tree to stdout

GLOBAL OPTIONS:
    -h, --help               Show help message
    -V, --version            Show Carven version
