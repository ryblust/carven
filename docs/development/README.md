# Development

These references guide changes to Carven's language, compiler, runtime, and
repository tests.

| Task | Reference |
| --- | --- |
| Organize and write project C++ | [Conventions](conventions.md): ownership boundaries, modules, naming, values, and failure handling |
| Place tests and validate a change | [Testing](testing.md): suite responsibilities, fixtures, assertions, builds, and static analysis |
| Evaluate a language or implementation design | [Principles](principles.md): semantic authority, native boundaries, safety, performance, and feature admission |

Use the [Language](../language/README.md), [Toolchain](../toolchain/README.md), and
[Compiler](../compiler/README.md) references for the contracts a change affects.
Repository-local task implementations and benchmark procedures are documented in
[Xmake](../../xmake/README.md).
